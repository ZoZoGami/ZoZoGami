## 🏆 Featured Projects

### 🛒 [Cheap Chip](https://github.com/ZoZoGami/Cheap_chip) — Circular Economy Hardware Marketplace & Repair System
* **Tech:** Next.js 16, React 19, MongoDB v7, NextAuth v5, Stripe, Groq AI (LLaMA 3.3 70B), MapLibre GL
* **Live Demo:** [cheap-chip.vercel.app](https://cheap-chip.vercel.app/home)
* An end-to-end hardware recycling marketplace featuring algorithmic chip repair quotes, a sub-second bilingual AI support copilot, real-time geospatial courier dispatch maps, and a 4-tier RBAC system with automated Stripe payroll.

### 🧠 [Parkinson's Disease Detection via Keystroke Dynamics](https://github.com/ZoZoGami/parkinsons-detection-keystroke-dynamics)
* **Tech:** Python, scikit-learn, XGBoost, SMOTE, SHAP (Explainable AI), Pandas
* Novel healthcare ML study analyzing 9M+ passive keystrokes from 227 subjects. Engineered **Circadian HoldTime Fluctuation** to model Levodopa medication cycles and built a **Soft Voting Ensemble achieving 69.2% accuracy** with full SHAP transparency.

### 📰 [News Topic Classification Benchmark](https://github.com/ZoZoGami/news-topic-classification-nlp)
* **Tech:** PyTorch, TensorFlow, Skip-gram Word2Vec, TF-IDF, GRU, LSTM, BiGRU
* Systematic empirical evaluation across 24 model permutations. Achieved **91.83% test accuracy (0.918 macro-F1)** with a Skip-gram GRU architecture, discovering that learned dense embeddings autonomously bypass HTML noise.

### ⚡ [JARVIS — Productivity & Academic Command Center](https://github.com/ZoZoGami/Jarvis-client)
* **Tech:** React 19, Vite, Express 5, MongoDB Atlas, JWT, Nodemailer, node-cron
* **API Engine:** [Jarvis-server](https://github.com/ZoZoGami/Jarvis-server)
* Full-stack student command center integrating real-time lecture countdown tracking, an interactive 7-day routine matrix with debounced cloud persistence, and a background cron daemon that sends automated email reminders before deadlines.

### 🏦 [Bank Customer Demographic Inference](https://github.com/ZoZoGami/bank-customer-demographic-inference)
* **Tech:** Python, scikit-learn, MLP Neural Network, RobustScaler, K-Means Clustering
* Predictive tabular modeling on 41,188 banking records to infer missing demographic age attributes and cluster clients into lifetime value cohorts.
